# رابط کاربری کاربان

Next.js App Router با رابط فارسی و RTL. مرورگر فقط `/api/v1/*` را صدا می‌زند.

```powershell
Copy-Item .env.example .env.local
npm install
npm run dev
```

`BACKEND_URL` فقط در سمت سرور Next.js استفاده می‌شود.

```powershell
npm run typecheck
npm run lint
npm run build
```

فرم‌ها با React Hook Form و Zod، وضعیت سرور با React Query، انتخاب‌ها و دیالوگ‌ها با Headless UI، و متن غنی با TipTap JSON هستند.
